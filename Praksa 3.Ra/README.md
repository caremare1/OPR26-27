## Windows Network Settings

Run `python network_settings.py` on Windows. The program lists connected adapters
and their current IPv4 settings. Changing settings requires running Python as
Administrator; applying a change can interrupt the network connection.

Presets are stored in `network_presets.json` and can be edited separately. In
the Presets mode, change the IP last number before applying the selected preset.
